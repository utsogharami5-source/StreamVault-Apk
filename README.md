# 📺 StreamVault v1.0.0

This application is made by **Utso**.

Welcome to **StreamVault** for Android! StreamVault is a premium IPTV client designed for watching 6,500+ Live TV Channels free with HLS streaming, custom playlists, and modern web integration.

---

## ✨ Features Highlight

### 🌍 6,500+ Live TV Channels
Access free worldwide broadcasts and channels directly from your mobile device.

### ⚡ Advanced HLS Player
Seamlessly stream HTTP Live Streaming (HLS) feeds with automatic quality handling.

### 📂 Custom Playlist Upload
Easily import your own M3U playlists and IPTV links using the built-in file selector.

### 🌐 Web Integration
Connected to our modern, responsive web app host for real-time updates and synchronization.

### 📱 Premium Mobile Experience
* **Full-Screen Video:** Seamlessly enter landscape mode when full-screen is requested.
* **Aspect Ratio / Screen Size Overlay Controls (Directly on Video):** Choose from **Fit** (contain aspect ratio), **Stretch** (fill screen), or **Zoom** (crop to cover screen) directly from the full-screen player layout. A tiny gear button overlays the top-right corner of the video player, allowing you to instantly scale the stream without leaving the video.
* **Sleek Navigation Sidebar (Home Screen Only):** Open the sidebar via a slide-out drawer or by clicking the menu button positioned in the **top-left corner**. The button, drawer, and swipe gestures are only accessible on the initial Home Screen and are completely hidden and disabled when a video is playing or when you navigate to other screens, ensuring a clean, distraction-free player.
* **Back Button Interception:** Exit the sidebar, close full-screen mode, or go back through browser history before closing the application.
* **Mixed-Content Support:** Configured to load mixed HTTP/HTTPS streams, which is essential for compatibility with local IPTV ISP servers.
* **Polished Offline/Error Screens:** If network connection fails, a beautiful Slate-themed screen allows easy retrying.
* **Dark Mode Splash Screen:** Aesthetic, responsive transition with dynamic load progress tracking.

## 📦 How to Install

1. Locate or download the signed APK: [app-release.apk](app/build/outputs/apk/release/app-release.apk)
2. Transfer the APK to your Android device if downloaded on a PC.
3. Open the APK on your device, enable **"Install from Unknown Sources"** if prompted by the operating system, and install StreamVault.
4. Launch and enjoy 6,500+ live streams!
